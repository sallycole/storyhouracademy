Tests

Use these tests for diagnostic information. Offer a pretest when students haven't yet been taught all the material. Offer a mastery test when students have been taught all the material. The tests are the same, but students may feel less pressure when taking a test labeled pretest.

Single-Sound Consonants (lowercase)

Test 16 single-sound consonants in lowercase: b, d, f, h, j, k, l, m, n, p, qu, r, t, v, w, z.

Pretest
Mastery Test

Single-Sound Consonants (uppercase)

Test 16 single-sound consonants in uppercase: B, D, F, H, J, K, L, M, N, P, Qu, R, T, V, W, Z.

Pretest
Mastery Test

Single-Sound Consonants and Consonant Digraphs

Test 21 single-sound consonants and consonant digraphs: b, ch, d, f, h, j, k, l, m, n, ng, p, qu, r, sh, t, th, v, w, wh, z.

Pretest
Mastery Test

Multi-Letter Vowel Phonograms

Test multi-letter vowel phonograms: ai/ay/eigh, ar, au/aw, ear, ee, er/ir/ur, igh, oa, oi/oy, or, our, ui, wor.

Pretest
Mastery Test

25 Vowel Phonograms

Test 25 vowel phonograms: a, e, i, o, u, y, ai/ay/eigh, ar, au/aw, ear, ee, er/ir/ur, igh, oa, oi/oy, or, our, ui, wor.

Pretest
Mastery Test

Alphabet Letters and their Associated Sounds

Test all 26 alphabet letters, a through z, with qu in place of q.

Pretest
Mastery Test

51 Phonograms

Test 51 phonograms: all alphabet letters plus ch, ck, ng, sh, th, wh, ai/ay/eigh, ar, au/aw, ear, ee, er/ir/ur, igh, oa, oi/oy, or, our, ui, wor.

Pretest
Mastery Test

Syllable Types

Test identifying the six syllable types (closed, open, vowel-consonant-e, vowel team, r-controlled, and consonant-le) across 36 words.

Pretest
Mastery Test

60 Phonograms

Test 60 phonograms: the 51 phonograms plus aigh, dg, ph, gh, gn, kn, wr, rh, tch.

Pretest
Mastery Test

75 Phonograms

Test 75 phonograms: the 60 phonograms plus augh, ea, eau, ei, eur, ew/eu, ey, gu, ie, oe, oo, ou, ough, ow.
